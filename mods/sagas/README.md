# Sagas

Landmarks from real 3D models (castles, ruins, temples, ships, statues), placed during map
generation where their site hints fit. This is the core mod: it maps material classes to the
nodes of the running game and decides where sagas go. The sagas themselves come in content packs
(`sagas_<theme>`), generated by the [luanti-sagas](https://github.com/culmat/luanti-sagas) tools.

## Supported games

Minetest Game, Mineclonia and VoxeLibre (tested headlessly). Other games work with the generic
fallback (mapgen aliases and node names); unresolved material classes stay visible as striped
placeholder blocks.

## For pack authors

```lua
sagas.register({
	id = "medieval:watchtower",            -- theme:name
	schematic = modpath .. "/schematics/watchtower.mts",
	size = {x = 12, y = 24, z = 12},
	anchor = {x = 5, y = 0, z = 5},        -- ground contact point (layer 0 replaces the surface)
	site = {"cliff+coast", "cliff+river", "waterfall"},
	exposure = "prominent",                -- prominent | hidden | any
	biomes = {"any"},                      -- desert savanna grassland forest jungle taiga snow tundra mountain swamp beach ocean mushroom
	materials = {context = "surroundings", overrides = {roof_red = "fixed"}},
	rarity = 400,                          -- about one per 400 mapchunks where it is tried
})

sagas.register_on_placed(function(id, anchor, box, rotation, game_info)
	-- add loot, mobs, signs ...
end)
```

Schematics contain only `air`, `sagas:color` (param2 = palette index) and `sagas:m_<class>`
placeholders; never game nodes. Write them with the `sagas` tools, which also generate the
registry, licence and attribution files.

## Settings

See [settingtypes.txt](settingtypes.txt): rarity scale, disabled themes or sagas, sagas per
mapchunk, large sagas, lore, flowing water, no automatic placement, debug.
